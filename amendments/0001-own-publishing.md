# Amendment 0001: Narthex generates its own published pages

**Status:** applied to `SPEC.md` v0.3.1
**Target:** `SPEC.md` v0.3.0
**Date:** 2026-10-17
**Ruling:** R23 (`notes/2026-10-17-rulings.md`), given in chat with special emphasis when the first set of
artifacts was published.

## A1: every published page comes from Narthex

New `REQ-DOC-16`: every page Narthex publishes is generated by Narthex's own tooling from the repo at a named
commit. That covers the decision form, the HTML editions of SPEC and OVERVIEW, and explainers. Each page can be
published to Narthex's own host and to any static host. claude.ai artifacts are one optional target.

New `INV-18`: no published page exists only as a claude.ai artifact. Each one has a source in the repo and a
generator in Narthex that can publish it elsewhere.

## A2: editions without identifier clashes

The v0.2.0 identifier map moved from Appendix A to `history/v0-id-map.md`. The traceability table no longer
opens rows with step identifiers. Both changes stop the HTML editions from defining an identifier twice.
