# Amendment 0005: who a practitioner is

**Status:** applied to `SPEC.md` v0.3.5
**Target:** `SPEC.md` v0.3.4
**Date:** 2026-10-17
**Ruling:** R34, given in chat while Pablo role-plays the user for the architecture phase.

The experience level `practitioner` (§3.3) is a seasoned vibe-coder: someone who has built several products
with AI, is starting to grasp the process, and reads about building software with AI, but is not yet an
expert. Engineers of other disciplines and self-taught coders stay in this level. `newcomer` keeps the first
product and casual vibe-coding.

Both rows of the experience-level table change; nothing else does. The decision form for the architecture phase
already writes for a practitioner.
