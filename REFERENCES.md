# References

## How this file is maintained

- This file lists the external sources behind Narthex's notes, amendments and spec. It is collected for Pablo's planned book on the whole system (ruling R6 in `notes/2026-10-17-rulings.md`).
- A note or amendment that cites a new external source adds it here in the same change.
- SPEC `REQ-KNB-8` requires this file, and the `research` skill keeps it current (`REQ-SKL-2`).
- There is one entry per source, deduplicated by URL, or by title when there is no URL. Entries are grouped by topic and sorted alphabetically by title within a group. A work the notes name without a link says "No URL in the notes".
- The markers [secondary] and [unverified] are copied from the note that cites the source. Do not add them on your own.
- Each entry lists the repo files that cite it.
