# Name search: "Narthex" (first screen, 2026-10-17)

A first trademark and domain screen for **Narthex** as the name of a software and developer-tools product
(Nice classes 9 and 42). It is a desk check with free web tools, not a clearance search. "Narthex" is
currently a codename ([codenames](2026-10-17-codenames.md)).

**This is not legal advice.** A lawyer's clearance search is needed before the name is adopted as a brand.

## Method and limits

- Official registers (USPTO, EUIPO, TMview, WIPO) are JavaScript apps that could not be queried from this
  environment: [WIPO Global Brand Database](https://branddb.wipo.int/en/quicksearch?by=brandName&v=narthex)
  returned only a bot check, and [TMview](https://www.tmdn.org/tmview/) returned an empty page. **Unverified:**
  nothing below comes from an official register.
- US marks come from the aggregator [Trademarkia search "narthex"](https://www.trademarkia.com/search/trademarks?query=narthex),
  which copies USPTO data and may lag. Goods and services text there is truncated.
- Package and repository checks used public APIs, listed in each row. Domain checks used RDAP and DNS and
  are **indicative only**.
